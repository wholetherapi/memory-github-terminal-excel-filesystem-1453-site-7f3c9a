# Submission archive

Uploads from the 2026 cohort.

Students upload from different tracks, editors and tools, so file names do **not**
follow one uniform convention. Each file opens with a header comment that describes
the upload; the file contents are the record of what was submitted.

Redundant uploads, earlier drafts and occasional mislabelled files remain in the
folder. Files that are not listed in the cohort roster are guest or external uploads.
