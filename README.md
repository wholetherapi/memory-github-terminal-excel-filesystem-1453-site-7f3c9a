# Larchwood Learning Studio - course site

Static course site for the Larchwood Applied Engineering Studio.

## Layout

- `_config.yml` - site configuration and author block
- `_data/` - generated data files consumed by the site templates
- `curriculum/milestones.yaml` - programme calendar
- `enrollment/cohort-2026.yaml` - cohort roster
- `submissions/` - learner uploads archive (see the archive README)

Deployment is handled by the studio's site pipeline; do not commit build output.
